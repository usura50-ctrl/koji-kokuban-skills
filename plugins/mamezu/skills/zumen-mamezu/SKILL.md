# 図面から豆図と黒板Excelを作る

図面のPDF（CAD出力で、文字が読み取れるもの）の一覧表から、**符号ごとの断面の画像（豆図）**と、**黒板の文字を入れたExcel**を作る。Excelは、工事黒板アプリ（PC版「黒板作成」の「Excelを取り込む」）で読み込める。

決めてあるルールは `references/rules.md`。**作業の前に読むこと。**
プログラムは、このスキルの `scripts/` フォルダにある（以下、`scripts/` と書く）。

## 進め方（この順に行う）

### 1. 準備
1. 図面PDFのパスを確認する（指定が無ければ、質問する）。
2. `python scripts/check_env.py` を実行する。足りない部品（PyMuPDF・Pillow・openpyxl・numpy）は、自動で入る。Pythonが無い場合は、入れ方を案内する（python.org から、Python 3.10 以上）。
3. **質問画面（AskUserQuestion）で、次を聞く。**
   - **工種**：鉄筋工事（初めの選択肢）／その他（入力）。毎回、必ず聞く。
   - **出力先**：デスクトップの「豆図出力」＋案件名のフォルダ（初めの選択肢）／その他（入力）。

### 2. 作る
```
python scripts/run_project.py "<図面PDF>" "<出力先>" "<工種>"
```
- 図面の全ページから、一覧表（「符号」の欄がある表）を自動で見つけ、画像とExcelを作る。
- 出力：`<出力先>/<まとまり>/<符号>.png`（まとまり＝基礎梁・柱・梁・壁）、`黒板_基礎梁・柱・梁・スラブ・壁.xlsx`、`確認してください.txt`。
- 画面に出た「確認が必要な点」を、手順4で使う。

### 3. 実行したあとに、画像を見て確認する（省略しない）
1. `python scripts/contact_sheet.py "<出力先>"` で、まとまりごとの一覧画像を作る。
2. 一覧画像を、すべて開いて（Read）、見る。確認すること：
   - 画像が、断面の図になっているか（文字だけ・空・切れ・別の図が混ざっていないか）。
   - 符号の名前（左上の番号とファイル名）が、図の内容と合っているか。
   - 縦長の図が「豆図付き（上部拡大）」、それ以外が「豆図付き」になっているか。
3. **図面と見比べて、値を確認する。** 各一覧表（ページ）から、2〜3件を選び、`python scripts/show_rows.py "<Excel>" <まとまり> <最初の番号> <件数>` で黒板の文字を出し、図面のそのページ（PDFのページをReadで開く）の表と比べる。符号・階・位置・寸法・主筋・帯筋（STP・フープ）・腹筋・幅止め筋・備考が、合っているか。
4. 並び順を確認する：まとまりごとに、下の階から、符号の若い順。
5. 見つけた問題は、プログラムの読み取りの癖（項目名の言葉の違いなど）か、図面の読み方の問題かを、切り分ける。直せるなら直して、再実行する。

### 4. 迷う・確認が必要なことは、質問画面（AskUserQuestion）で聞く
勝手に決めずに、**選択式の質問（最後に「その他」で入力できる）**を出す。例：
- `確認してください.txt` の項目：題名が読めない表の扱い、値のない符号（「S-26参照」など）を飛ばしてよいか、頭に記号が付いていない値（コ型スターラップなど）の書き方。
- 同じ名前の黒板が複数ある（同じ符号が複数のページにある。図面の間違いの可能性が高い）：教えて、どうするか聞く。
- ルールに無い表（カットオフ長さの表など）を、黒板にするか。
- 画像の問題（切れている・図でない）を、直す方法が複数あるとき。
質問は、1つずつ具体的に。選択肢には、お勧め（Recommended）を付ける。

### 5. 報告する
- 件数（まとまりごと）、飛ばしたもの、確認が必要な点、私（Claude）が見て確認した内容と結果を、短く報告する。
- 出力先のフォルダを案内する。
- アプリでの取り込み方：PC版アプリで案件を開く → 「黒板作成」→「Excelを取り込む」→ Excelを選ぶ → 「画像のフォルダを選ぶ」で、**出力先のフォルダ（まとまりごとのフォルダの親）**を選ぶ → 「今の予定に追加する」→「保存」。
- ユーザーに、画像を見てもらい、直す点を聞く。

## 注意
- 図面のPDFは、そのPCの中だけで処理する（外部に送らない）。
- 出力先に、同じ名前のフォルダがあるときは、中身が入れ替わる。上書きしてよいか、先に確認する。
- 図面が、文字の読み取れないPDF（スキャン・画像）の場合は、この方法は使えない。その旨を伝える。
