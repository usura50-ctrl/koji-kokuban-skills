# 決めてあるルール（ユーザーと決めたもの）

## 切り出し（豆図の画像）
- 一覧表の「断面」の欄の中身を、**文字・引出し線・寸法線も含めて**、枠線を除いて、できるだけ大きく切り出す（長い辺 約2400px）。項目欄（左端の項目名）は付けない。黒板に文字を転記するため。
- 柱は「階×符号」、大梁は「階×符号×位置（端部・中央・Y1端など）」、基礎梁・小梁・壁は「符号（×位置）」ごとに1枚。
- 図面に書き込まれた色付きの枠（赤・緑・黄）は、画像から消す。
- 斜線の欄・空の欄は飛ばす。結合セル（複数の位置にまたがる寸法・STPなど）の値は、それぞれの位置の黒板に、同じ内容を書く。
- 柱の「仕口部フープ」の行は、含めない（その階だけ）。
- 同じ符号が複数のページに出てきたら、図面の間違いの可能性が高いので、ユーザーに知らせる。
- 一覧表でない図（要領図など）を切り出したいときは、図面に赤枠が付いている（赤枠の内側を、文字ごと切り出す）。

## ファイル名
- 基礎梁・小梁・壁：`FG1全断面`、`B2端部`、`W15`。柱：`C1_5階`。大梁：`G4_6階X12端`、`G1_R階Y1端`。

## まとまり（フォルダ・Excelの「まとまり」）
- ページでは分けず、部材の種類で、**基礎梁・柱・梁（大梁＋小梁）・スラブ・壁** の5つにまとめる（地中梁・地中小梁は「基礎梁」）。基礎スラブ・片持ちスラブは「スラブ」。壁・耐震壁は「壁」。

## Excelの並び（撮影の順）
- まとまりの順：基礎梁 → 柱 → 梁 → スラブ → 壁。
- まとまりの中：①下の階から（1階→…→R階） ②符号の若い順（C1, C2, …／G1, G2, …）。階のない小梁などは、大梁のあと。
- 理由：1階のG1から撮影するため。8階が先頭だと、画面を最後までスクロールして選ぶことになり、不便。

## 黒板の文字（作業内容）
- 1行目：`符号：階　位置　幅×せい`（例：`G4：6階　X12端　500×700`、`FG1：全断面　650×2500`、柱は `C1：5階　600×800`）。
- 続けて、図面の項目名のまま、1項目1行：上端筋／下端筋（別の行）／スターラップ（STP）／腹筋／主筋／フープ（HOOP）など。
- 帯筋（STP・フープ）の記号（□）は、図なので文字にない。`□-D13@100` のように補う。本数は、□の前（`3□-K13@100`）。
- 幅止め筋：特記事項（「巾止筋はD10-@1000以内」など）から読み取り、**梁・壁には「幅止め筋：D10@1000」の行を必ず足す**（柱には足さない）。
- 備考があれば、最後に書く。
- スラブは、豆図なし・黒板の種類は「標準」。文字だけ。`S15　版厚150`／`短辺(主筋)：上端筋 D10・D13@200　下端筋 D10@200`／`長辺(配力筋)：…`／備考。
- 壁：`W15：壁厚150`／縦筋／横筋／`開口部補強筋：縦2-D13　横2-D13　斜メ1-D13`／幅止め筋。

## 黒板の種類・豆図領域幅（Excelの列）
- 工種：毎回、ユーザーに聞く（初めの選択肢は鉄筋工事）。
- **縦長（高さ＞幅）の画像は「豆図付き（上部拡大）」**。豆図領域幅は、画像から計算した値（狭い・普通・広い）。
- **縦長でない画像（柱・大梁など）は「豆図付き」で、豆図領域幅は「普通」（標準）。**
- スラブは「標準」（豆図なし）。

## 確認（省略しない）
- 実行したあとに、Claudeが画像（一覧画像）を見て確認し、図面と値を見比べる。迷うこと・確認が必要なことは、質問画面（選択式＋その他）で聞く。
